### 👨‍💻 Sobre Mí

Soy **Ingeniero de Software y Arquitecto de Soluciones Web/Móviles** con un enfoque marcado en el rendimiento, la accesibilidad y el diseño de sistemas escalables. Lidero el desarrollo integral del ecosistema **UBICATEC**, una suite tecnológica orientada a la navegación espacial asistida, telemetría y comunicación comunitaria en el **Instituto Tecnológico de Puebla (ITP)**, obra registrada y protegida legalmente ante el **INDAUTOR**.

- 🚀 **Liderazgo Técnico:** Dirección de proyectos desde la concepción hasta producción, coordinando arquitecturas Frontend, Mobile (Android), Cloud Serverless y gobernanza de datos.
- 📱 **Desarrollo Móvil Avanzado:** Especializado en aplicaciones nativas con **Kotlin + Jetpack Compose** (Material 3, arquitectura MVVM, criptografía de Keystore AES-256 y biometría) y contenedores híbridos de alto rendimiento con **Capacitor 8**.
- 🌐 **Arquitecturas Web Offline-First:** Experiencia en PWAs con Service Workers personalizados (*Stale-While-Revalidate*, *Cache Storage*), motores vectoriales cartográficos GIS (**Leaflet**) y procesamiento de lenguaje natural heurístico.
- ☁️ **Cloud & DevOps:** Integración con la suite empresarial de **Firebase** (Firestore, Realtime DB, Storage, FCM, Auth RBAC), redes Edge en **Vercel** y pipelines de automatización con GitHub Actions.
