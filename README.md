### 🌐 1. UBICATEC 2.0 — Plataforma Web Progresiva (PWA)
<p align="center">
  <a href="https://github.com/Richpol99/ubicatec-showcase">
    <img src="https://raw.githubusercontent.com/Richpol99/ubicatec-showcase/main/assets/banner.png" width="480" alt="UBICATEC Web Banner" />
  </a>
</p>

Motor cartográfico para el campus del ITP con funcionamiento **100% Offline-First** sin dependencias de frameworks pesados, garantizando máxima velocidad en dispositivos móviles.
- 🗺️ **GIS Vectorial:** Renderizado de edificios, aulas, sanitarios y puntos de reunión sobre Leaflet + OpenStreetMap.
- 🎯 **HUD de Distancia:** Detección de posición y cálculo de distancia euclidiana en tiempo real con geolocalización.
- 🔍 **Smart Search NLP:** Búsqueda predictiva con tolerancia a errores tipográficos y alias estudiantiles (*"el domo"*, *"donde dan credenciales"*).
- 🕹️ **Gamificación en Canvas 2D:** Minijuegos clásicos recreados con física delta-time y tabla de récords en Firebase RTDB.

### 📱 2. UBICATEC Mobile — Aplicación Nativa para Android
<p align="center">
  <a href="https://github.com/Richpol99/ubicatec-android-showcase">
    <img src="https://raw.githubusercontent.com/Richpol99/ubicatec-android-showcase/main/assets/banner.png" width="480" alt="UBICATEC Android Banner" />
  </a>
</p>

Contenedor móvil híbrido de ultra-bajo consumo impulsado por **Capacitor 8** y **Java 21**, diseñado para integrarse profundamente con el sistema operativo Android (API 24 hasta API 36).
- 📱 **Widgets de Pantalla de Inicio:** Lanzador de 4 accesos rápidos (Inicio, Mapa, Redes, Equipo) y barra de búsqueda directa desde el escritorio del smartphone.
- 🖼️ **Inmersión Edge-to-Edge:** Implementación de `WindowInsetsControllerCompat` para aprovechar la pantalla completa con barras de sistema transparentes.
- 🔗 **Enrutador de Deep Linking:** Despacho nativo de Intents que cargan vistas y búsquedas instantáneas en la WebView local (`http://localhost/`).
- ⚙️ **Plugin Nativo de Ajustes:** `UbicatecSettingsPlugin` para redirigir directamente al usuario a la activación del GPS del sistema.

### 📊 3. UbiDash — Consola Ejecutiva & Telemetría en Jetpack Compose
<p align="center">
  <a href="https://github.com/Richpol99/ubicatec-admin-showcase">
    <img src="https://raw.githubusercontent.com/Richpol99/ubicatec-admin-showcase/main/assets/ubidash-badge.png" width="280" alt="UbiDash Badge" />
  </a>
</p>

Aplicación **100% nativa en Kotlin 2.0 y Jetpack Compose** con Material 3 y tema Glassmorphism oscuro. Es el centro neurálgico que administra y monitoriza todo el ecosistema UBICATEC.
- 🛡️ **Biometría & Criptografía Keystore:** Desbloqueo por huella/rostro (`BiometricPrompt`) y almacenamiento de credenciales cifrado en **AES-256 GCM** (`EncryptedSharedPreferences`).
- 👥 **Control de Acceso (RBAC):** Validación de Claims (`superadmin`, `admin`, `editor`) con registro inmutable de auditoría (`admin_audit_logs`).
- 📈 **Telemetría & Heatmap en Vivo:** Métricas DAU/MAU con análisis comparativo de 7/30/90 días y mapa de calor de edificios más buscados y visitados.
- 📄 **Generador de Reportes PDF:** Compilación nativa vectorial de informes directivos con `android.graphics.pdf.PdfDocument` y exportación CSV.
- 🚨 **Consola de Alertas de Emergencia:** Emisión instantánea de notificaciones push prioritarias (OneSignal + FCM) para contingencias y alerta sísmica.
